# cpp-programming-fundamentals

My C++ practice codes, lab exercises, and fundamental programs from BSCS 1st Semester at GCWUF.

## 🚀 Lab Exercises & Progress

* **01_hello_world.cpp**: Printed "Hello, World!" on the console.
* **02_student_info.cpp**: Printed personal information (Name, University, Department) on separate lines.
* **03_addition_program.cpp**: Takes two integer inputs from the user and displays their sum.
* **04_subtraction_program.cpp**: Takes two integer inputs from the user and calculates their difference.
* **05_multiplication_program.cpp**: Takes two integers inputs from the user and display their multiplication.
